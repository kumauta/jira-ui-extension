# Jira UI Extension

Jira Cloud のコメント欄で「他のコメントを表示」を自動でクリックし、過去のコメントを順次読み込む Chrome 拡張機能です。
右側メニューの下部にはコメント一覧を表示し、最初・最後・各コメントへ移動できます。

## インストール

1. Chrome で `chrome://extensions` を開き、「デベロッパー モード」をオンにします。
2. 「パッケージ化されていない拡張機能を読み込む」を押します。
3. このリポジトリのフォルダー（`manifest.json` がある場所）を選びます。
4. 開いている Jira タブを再読み込みします。

ビルドや npm install は不要です。コードを更新したら拡張機能の「再読み込み」を押し、Jira タブも再読み込みしてください。

## 動作

- 対象は `https://*.atlassian.net/browse/*`（各サイトの Jira 課題ページ）です。
- アクティビティの「コメント」タブで、表示されている展開ボタンを自動でクリックします。コメントタブ自体の選択は変更しません。
- 初回表示、課題間の画面切り替え、コメントタブへの切り替え、複数回の追加読み込みに追従します。
- 読み込み中はクリックせず、クリック間隔は最低 1.5 秒です。コメント数が増えない場合は 3 回で停止します。再試行するにはページを再読み込みしてください。
- Jira 本来の追加読み込みを利用するため、取得完了までは一時的に折りたたまれた状態が見えます。コメントが多い課題は読み込みに時間がかかります。
- コメントの投稿・編集・削除や独自の API 通信、外部送信、データ保存は行いません。

## コメントへの移動

- 「コメント」タブ表示中、右側メニューの下部にコメント一覧を表示します。
- 「最初のコメントへ」「最後のコメントへ」は、画面上の並び順の先頭・末尾へ移動します。
- 各リンクは本文の先頭の空でない行です。画像のみのコメントは「画像のみ」と表示します。
- 長いタイトルは1行で省略し、マウスを重ねると全文を確認できます。
- 追加読み込み、コメントの追加・編集・削除、並び順の変更に合わせて一覧を更新します。
- 色は Jira のテーマ設定に追従します。一覧が長い場合は一覧内でスクロールできます。

Jira の DOM 識別子が変更された場合は `content.js` のセレクターの更新が必要です。Manifest V3 の [content scripts](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts) を使用しています。
